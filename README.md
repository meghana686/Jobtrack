# JobTrack - Software Job Application Tracker

JobTrack is a professional, minimalist web application built to help software developers manage their job hunt efficiently. It replaces messy spreadsheets with a clean, responsive dashboard.

## 🚀 Features
- **Dashboard Stats:** Quick overview of Applied, Interview, Selected, and Rejected counts.
- **Full CRUD:** Add, View, Edit, and Delete job applications.
- **Search & Filter:** Find specific companies or filter jobs by status and application date.
- **Dark/Light Mode:** Toggle between themes (persists via localStorage).
- **Fully Responsive:** Works seamlessly on Desktop, Tablets, and Mobile.
- **No Backend Needed:** Uses browser `localStorage` for data persistence.

## 🛠️ Technologies Used
- **HTML5:** Semantic structure.
- **CSS3:** Custom properties (variables), Flexbox, and Grid.
- **Vanilla JavaScript:** DOM manipulation, Event listeners, and LocalStorage API.

## 📂 Folder Structure
- `index.html`: Landing Page.
- `dashboard.html`: Analytics overview.
- `applications.html`: Table of all applications.
- `add-application.html`: Form to create/update jobs.
- `css/style.css`: All styling (Theme-aware).
- `js/`: Modular scripts for different pages.

## 🏁 How to Run
1. Clone the repository or download the ZIP.
2. Open `index.html` in any modern web browser.
3. No server or installation required!
